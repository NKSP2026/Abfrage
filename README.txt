Ergänzung gegenüber V49:
- Neue interaktive Körperflächenkarte bei Verbrennung / Verbrühung / Verätzung.
- Mehrere kleine Körperflächenfelder können gleichzeitig ausgewählt werden.
- Die Auswahl wird als orientierende VKOF in Prozent berechnet und in Einsatztext/Verdachtsvorschlag übernommen.
- Verwendet die hochgeladene Körperkarte als visuelle Orientierung.
- Bestehende V49-Fragen und Funktionen bleiben erhalten.
